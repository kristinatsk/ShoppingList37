# 🛒 Список покупок

**Список покупок** — минималистичное iOS-приложение для создания и управления списками покупок. Позволяет организовывать покупки, отслеживать приобретённые товары и быстро составлять новые списки на основе предыдущих.

## 📱 Основные возможности

### Управление списками покупок
- Создание списков с произвольными названиями.
- Переименование и удаление существующих списков.
- Дублирование списков с автоматическим добавлением порядкового номера к названию.
- При дублировании все товары копируются в новый список со статусом «Не куплено».

### Управление товарами
- Добавление товаров с указанием названия, количества и единицы измерения.
- Редактирование параметров и удаление товаров.
- Отметка приобретённых товаров.
- Автоматические подсказки на основе ранее добавленных товаров для быстрого заполнения списков.

### Организация покупок
- Сортировка товаров по алфавиту или вручную.
- Очистка списка от приобретённых товаров.

### Хранение данных
- Локальное хранение списков и товаров с помощью SwiftData.
- Сохранение данных между запусками приложения.

### Интерфейс
- Поддержка светлой и тёмной тем.
- Минималистичный интерфейс с использованием SwiftUI.

## 🛠 Технологический стек

- **Язык:** Swift 6.0
- **UI:** SwiftUI
- **Архитектура:** IVO (Intent–View–Observable)
- **Асинхронность:** Swift Concurrency (async/await)
- **Хранение данных:** SwiftData
- **Анализ качества кода:** SwiftLint
- **Минимальная версия iOS:** 17.0
  
### Мой вклад в проект
- Создание и редактирование списков покупок, включая основной экран со списками.
- CRUD-операции со списками и товарами: создание, редактирование, дублирование, удаление и отметка выполнения.
- Автоматические подсказки товаров на основе ранее добавленных позиций, чтобы пользователю не приходилось каждый раз вводить названия заново.
- Поддержка светлой и тёмной тем, работу с цветами, иконками и графическими ресурсами.
- Локализация приложения на английский язык.
